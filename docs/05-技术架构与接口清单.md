## 一、技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | Vue 3 + Vite + TypeScript | 组合式 API |
| 前端 UI | TDesign（`tdesign-vue-next`） | 遵循 `DESIGN.md` 设计系统：Action Blue #0066cc 单一强调色、SF Pro 负字距、纸白表面、pill 圆角 |
| 状态管理 | Pinia | 用户态、全局配置 |
| 路由 | Vue Router | 登录守卫 |
| 请求 | Axios | 拦截器统一带 token、错误提示 |
| 图表 | ECharts（扩展报表用） | |
| 后端 | Node.js + NestJS（推荐）或 Express + TypeScript | 结构化、DI、守卫做权限 |
| ORM | Prisma（推荐）或 Sequelize / mysql2 | 数据表见 03 文档 |
| 鉴权 | JWT（本系统会话）+ 飞书端内免登（网页授权 OAuth 备选） | |
| 飞书 | `@larksuiteoapi/node-sdk` | token/通讯录/审批/消息 |
| 数据库 | MySQL 8.x | InnoDB / utf8mb4 |
| 定时任务 | node-cron | 审批对账、超时提醒、通讯录/日历同步 |
| 部署 | Node 服务 + Nginx 反代 + HTTPS | 事件回调必须 HTTPS |

## 四、REST API 清单

> 统一前缀 `/api`，除登录回调外均需携带 JWT。鉴权分为 `ADMIN`（管理员）、`OWNER`（项目负责人）、`USER`（本人/普通）。

### 4.1 认证与用户

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/auth/feishu/login` | 公开 | 端内免登：收 code → 换 user_access_token → 拉用户 → 签发 JWT（主） |
| GET | `/auth/feishu/authorize` | 公开 | 302 跳飞书授权（浏览器访问备选） |
| GET | `/auth/feishu/callback` | 公开 | 网页授权回调，换 token，写会话（浏览器访问备选） |
| POST | `/auth/logout` | 登录 | 退出 |
| GET | `/auth/me` | 登录 | 当前用户信息 + 是否管理员 |
| GET | `/users` | 登录 | 通讯录用户列表（搜索/分页，走缓存） |
| POST | `/users/sync` | ADMIN | 手动同步通讯录 |

### 4.2 项目

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/projects` | 登录 | 项目列表（分页/搜索/状态） |
| GET | `/projects/:id` | 登录 | 项目详情 |
| POST | `/projects` | ADMIN | 新增项目（指定负责人） |
| PUT | `/projects/:id` | ADMIN/OWNER | 编辑项目 |
| DELETE | `/projects/:id` | ADMIN | 删除（软删除/归档） |
| PUT | `/projects/:id/members` | ADMIN/OWNER | 调整负责人/成员 |

### 4.3 报工

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/reports` | 登录 | 报工列表（人/项目/日期/状态筛选） |
| GET | `/reports/:id` | 登录 | 报工详情 |
| POST | `/reports` | 登录 | 提交报工（含审批判定，见模块3） |
| PUT | `/reports/:id` | USER(本人)/ADMIN | 编辑（仅审批前） |
| DELETE | `/reports/:id` | USER(本人)/OWNER/ADMIN | 撤销（同步撤销飞书审批实例） |

### 4.4 日历

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/calendar/is-holiday?date=` | 登录 | 判断某日是否节假日 |
| GET | `/calendar/rules` | 登录 | 日历例外列表 |
| POST | `/calendar/rules` | ADMIN | 新增例外 |
| DELETE | `/calendar/rules/:id` | ADMIN | 删除例外 |
| POST | `/calendar/sync` | ADMIN | 自动同步节假日接口（可选） |

### 4.5 系统管理

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/admin/list` | ADMIN | 管理员列表 |
| POST | `/admin` / DELETE `/admin/:openId` | ADMIN | 增删管理员 |
| GET/PUT | `/config` | ADMIN | 系统配置 |
| GET | `/audit-logs` | ADMIN | 操作日志 |
| GET | `/stats/hours` | ADMIN | 工时统计（扩展） |

### 4.6 内部回调/任务（非用户调用）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/internal/feishu/approval-callback` | 飞书审批事件订阅地址（需校验/解密） |
| POST | `/internal/messages/send` | 消息发送（可由 job/业务调用） |

## 五、定时任务（node-cron）

| 任务 | 频率 | 说明 |
|---|---|---|
| 审批对账 | 每 5 分钟 | 拉取审批中实例状态，防丢事件 |
| 超时未审提醒 | 每 30 分钟 | 审批超 N 小时未处理 → 卡片提醒审批人 |
| 通讯录同步 | 每 6 小时 | 增量同步飞书用户到 `feishu_user_cache` |
| 节假日同步 | 每日 | 同步下一年节假日（可选） |
| token 刷新 | 提前刷新 | tenant_access_token 到期前刷新 |

## 六、里程碑规划（建议）

| 阶段 | 内容 | 产出 |
|---|---|---|
| M1 地基 | 飞书应用创建、端内免登、通讯录同步、项目 CRUD | 可登录 + 项目管理 |
| M2 报工核心 | 报工提交/列表、规则校验（8h/加班/节假日）、免审批生效 | 免审批闭环 |
| M3 审批闭环 | 审批实例创建、事件回调、状态回写、审批中编辑/撤销 | 审批闭环 |
| M4 通知 | 卡片消息：待审批/通过/驳回/超时提醒 | 通知闭环 |
| M5 完善 | 日历配置、管理员后台、审计日志、统计报表（可选） | 上线可用 |

## 七、待确认事项

1. 报工日期：是否允许补录历史日期？（当前建议：允许 ≥ 项目开始日期的过去日期，禁止未来日期）
2. 同人同项目同日：是否允许多条报工？（当前默认唯一，可放开）
3. 审批人：默认项目负责人，是否需多级审批 / 指定审批人？
4. 已审批通过的报工：如需更正，是否支持「撤销申请」（当前：不可直接改，可走撤销扩展）？
5. 管理员来源：仅用 `admin` 表维护，还是需要从飞书部门/角色自动映射？
6. 节假日同步：自维护（默认）还是对接第三方接口自动同步？
7. 统计报表是否纳入首期范围？
8. 部署环境与域名（事件回调需 HTTPS 域名）？
